# Sandbox

A reference for writing the docs, not a page for readers. Mihon's `sandbox` page is the pattern.

## Shortcodes

### In a sentence

::: info Example
To find every menu, go to <nav to="main_more">.
:::

::: info Example: a deep path
In <nav to="advanced">, try **Clear cache** and **Clear cookies**.
:::

::: info Example: an icon-only control
Select two entries, then tap <icon name="merge">.
:::

::: info Example: a key that does not exist
A typo is loud rather than blank: <nav to="no-such-screen">.
:::
