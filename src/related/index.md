# Related apps

Reikai is one of several Android readers in the same family. They all descend from Tachiyomi, they
all read the same `.tachibk` backups, and each went in a different direction.

This is context, not a recommendation. Nothing here is affiliated with Reikai, and none of these
projects has endorsed it.

<div class="rk-apps">

<a class="rk-app" href="https://mihon.app">
  <span class="rk-app-name">Mihon</span>
  <span class="rk-app-tag">upstream</span>
  <span class="rk-app-desc">The app Reikai is built on. Manga, webtoons and comics, actively maintained by a team. If you want the reading experience without anything Reikai adds, you want this.</span>
</a>

<a class="rk-app" href="https://tsundoku-otaku.github.io">
  <span class="rk-app-name">Tsundoku</span>
  <span class="rk-app-tag">novels</span>
  <span class="rk-app-desc">A Mihon fork built for light novels, and the reference Reikai's own novel reader is measured against. Worth a look if novels are all you read.</span>
</a>

<a class="rk-app" href="https://github.com/komikku-app/komikku">
  <span class="rk-app-name">Komikku</span>
  <span class="rk-app-tag">features</span>
  <span class="rk-app-desc">A Mihon fork with a large feature set, and where several of Reikai's own came from, including the details editor and the related-manga row.</span>
</a>

<a class="rk-app" href="https://github.com/null2264/yokai">

<a class="rk-app" href="https://github.com/LNReader/lnreader">

</div>

## Moving between them

Every app above except LNReader reads and writes the same backup format, so you can carry a library
across by backing up in one and restoring in the other. Whatever is specific to the app that wrote
the file does not travel. See [Backups](/docs/guides/backups) for what does.

Mihon keeps its own [list of the forks it endorses](https://mihon.app/forks/), which is longer than
this page and is about Mihon rather than Reikai.
